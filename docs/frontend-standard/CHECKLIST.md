# 实施与验收清单 · v1.0

日期：2026-11-23（Asia/Shanghai，UTC+8）。开发 AI 必须记录证据；未执行不得打勾。每项可标记“通过 / 不通过 / 未验证 / 不适用（理由）”。

## 开工前

- [ ] 完整读取主规范和当前项目规则，列出优先级与冲突。
- [ ] 确认本次授权路由、组件、模板与业务字段，不直接复制清册示例结构。
- [ ] 找到已有组件与主题入口，列复用映射；不为换肤迁移框架。
- [ ] 保留现有产品名/logo；缺失资产只用文字，品牌覆盖有批准和版本。
- [ ] 规划同名浅深 token、按钮状态、内容状态和键盘路径。

## 令牌与视觉

- [ ] `python3 validate.py` 通过，JSON/CSS/主规范表格一致；项目覆盖另行实算。
- [ ] 组件引用语义变量，无散落 HEX/随意 color-mix；完整颜色不套 hsl()。
- [ ] 正文桌面计算样式为14/22px；窄屏16/24px；12px只用于非关键辅助信息。
- [ ] 标题16/20/24层级清楚，主字段/按钮未缩到12px；用户缩放不截字。
- [ ] 默认间距4/8序列；控件radius8、卡片12；非默认胶囊或重阴影。
- [ ] 必要边界使用control-border；border仅为装饰分割线。
- [ ] 主操作、状态色和图表语义独立；状态有文字，图表有标签/纹理/线型。

## 控件状态（浅/深分别核对）

- [ ] 主/次/ghost/文字/危险按钮都有default、hover、active、focus-visible、disabled、loading。
- [ ] 输入有default、hover、focus、invalid、readonly、disabled；selected状态同步语义属性。
- [ ] 常规桌面按钮/输入min-height36px，紧凑32px；没有无依据放大整页按钮。
- [ ] 触控主要操作可点击区域≥44×44px；coarse pointer的常用目标合理扩展。
- [ ] 图标按钮有可访问名称；tooltip不是唯一说明；hover操作也可键盘访问。
- [ ] placeholder使用不透明text-muted，不叠加opacity。
- [ ] loading不抖宽、不重复提交；禁用状态确实阻止所有激活路径。
- [ ] 独立状态/错误文字用*-text；深色实心按钮有control-border可辨轮廓。

## 布局与滚动断言

- [ ] 长列表滚到底，侧栏品牌/顶栏的视口位置不变，body没有第二个页面纵向滚动条。
- [ ] 主内容为页面滚动主体；长导航只在自身导航区滚动。
- [ ] 只有一个当前位置表达；侧栏当前项+标题可共存，无同级重复面包屑。
- [ ] 一个页级主要操作组、组内最多一个主按钮；表单页头不重复底栏提交。
- [ ] 表单滚到最后字段，字段/错误/焦点不被底栏覆盖；底栏不跨侧栏。
- [ ] 200%缩放、软键盘、窄屏操作条换行后，保存与取消均可达。
- [ ] 表格单行min-height约40px，长内容自然增高；冻结表头不遮页头。
- [ ] 表格局部横滚可用，应用整体不横滚；卡片和字段没有无提示裁切。

## 页面与数据状态

- [ ] 列表：搜索筛选、重置、排序、分页、选中/批量范围语义正确。
- [ ] 详情：分组字段清楚、空值与0不同、长编号可读/可复制。
- [ ] 表单：label真实关联、必填说明、帮助/错误id、aria-invalid/describedby、错误后输入保留。
- [ ] 总览：少量中性指标与待办，时间口径真实，无填充式彩色KPI。
- [ ] 覆盖首次空、筛选空、首次加载、后台刷新、读取失败、权限不足、局部失败；离线按实际支持范围测。
- [ ] 0/1/大量行、长中文、长产品名、无空格编号、缺值均不破坏布局。

## 键盘与无障碍

- [ ] 全程仅键盘完成导航、筛选、打开详情、提交/纠错、菜单与关闭弹层。
- [ ] Tab顺序合理，无正tabindex；跳到主内容链接可用；一个h1，地标和标题清楚。
- [ ] focus-visible清晰，2px轮廓+2px间隙，不被overflow/sticky裁掉。
- [ ] 弹层有标题/描述，锁焦点、背景inert、Escape与关闭回焦正确。
- [ ] 正文/按钮文字≥4.5:1，大字≥3:1，必要边界/图标/焦点≥3:1；项目新组合实算。
- [ ] 禁用和装饰例外没有被滥用；颜色不是唯一信号；forced-colors仍有系统可见轮廓。
- [ ] 读屏检查字段名、当前导航、排序、选中、错误关联和反馈播报；toast不淹没读屏。
- [ ] prefers-reduced-motion下无非必要移动/闪烁，仍有清晰进度说明。
